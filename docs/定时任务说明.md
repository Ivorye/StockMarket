# 定时任务说明

## 概述

项目通过 Windows 任务计划程序（schtasks）实现两个定时任务，按顺序每日自动执行数据更新和策略筛选。

| 任务名称 | 执行时间 | 脚本 | 功能 |
|----------|----------|------|------|
| StockDailyUpdate | 每日 20:00 | `dailyUpdate.py` | 股票列表更新 + 日线数据加载 |
| StockRunStrategies | 每日 00:00 | `runAllStrategies.py` | 全策略筛选 |

## 任务1: StockDailyUpdate（每日数据更新）

**脚本**: `dailyUpdate.py`

**执行步骤**:
1. `getStockBasic()` — 获取最新股票列表（Tushare API，每日限5次）
2. `loadAllBasic(df)` — 增量写入 `stockshare.stocks` 总表
3. `createStockTable(df)` — 为新股票创建 `gp{symbol}` 日线表
4. `insertNewTransactonRecordForAllStocks(df)` — 加载近7天日线数据（增量，已有记录跳过）

**日志**: `logs/daily_update.log`

**预计耗时**: 约2.3小时（~5500只股票，每只限速1.5秒）

**注册命令**:
```bat
:: 以管理员权限运行
setup_task.bat
```

**手动触发**:
```bat
schtasks /run /tn "StockDailyUpdate"
```

**查看状态**:
```bat
schtasks /query /tn "StockDailyUpdate" /v
```

**删除任务**:
```bat
schtasks /delete /tn "StockDailyUpdate" /f
```

## 任务2: StockRunStrategies（全策略筛选）

**脚本**: `runAllStrategies.py`

**执行策略**（共6个，使用近30天数据）:

| 序号 | 策略 | 说明 | 数据源 |
|------|------|------|--------|
| 1 | 放量涨幅 | 当日成交量>=前日3倍 且 涨幅>6%，结果写入 `st_daily_signal` 表 | DB (sm.st_daily) |
| 2 | 巨量上涨 | 放量>=2倍且涨超4%，之后缩量调整振幅<3% | Tushare API |
| 3 | 向上跳空缺口 | 最近一天低点高于前一天高点 | Tushare API |
| 4 | 跳空上涨 | 历史有过跳空且量能确认 | Tushare API |
| 5 | 翻倍股 | 区间内股价翻倍 | DB (sm.st_daily) |
| 6 | 放量日 | 当日成交量>=前日3倍 | Tushare API |

**日志**: `logs/strategies.log`

**预计耗时**: 约2小时（5个策略各遍历~4600只股票，API限制200次/分钟）

**注册命令**:
```bat
:: 以管理员权限运行
setup_strategy_task.bat
```

**手动触发**:
```bat
schtasks /run /tn "StockRunStrategies"
```

**查看状态**:
```bat
schtasks /query /tn "StockRunStrategies" /v
```

**删除任务**:
```bat
schtasks /delete /tn "StockRunStrategies" /f
```

## 限速说明

| API 接口 | 速率限制 | 应对措施 |
|----------|----------|----------|
| `pro.stock_basic()` | ~5次/天 | 仅在 dailyUpdate.py 中调用1次 |
| `pro.daily()` | 50次/分钟 | `loadStocks.py` 中每只股票 sleep 1.5秒 |
| `ts.pro_bar()` | 200次/分钟 | `stockPolicy.py` 中每100只 sleep 5秒 |

## 数据库依赖

| 数据库 | 用途 | 凭据 |
|--------|------|------|
| stockshare (pymysql) | 每股独立表 `gp{symbol}`、总表 `stocks` | root / P@ssw0rd |
| stockshare (mysql.connector) | `st_basic`、`st_daily`、`st_daily_signal` | root / P@ssw0rd |

## 文件清单

```

├── setup_strategy_task.bat   # 注册策略筛选定时任务

```

## 注意事项

- 两个批处理脚本需以 **管理员权限** 运行才能注册定时任务
- 非交易日运行时，日线数据加载步骤不会新增数据（增量逻辑自动跳过已有记录）
- 策略2-4、6 调用 Tushare `pro_bar` 接口，全量运行耗时较长，可在脚本中注释掉不需要的策略
- 策略1（放量涨幅）结果会持久化到 `st_daily_signal` 表，其他策略结果仅记录在日志中
